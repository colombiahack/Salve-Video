## Qué es

App de Android para descargar videos. Pega un enlace o compártelo desde otra app y se guarda en tu teléfono (Películas/SaveTools).

## Características

- Descarga con barra de progreso y cancelación.
- Integración con el menú **Compartir** de Android.
- Guardado automático en la galería.
- Actualización del motor de descarga (yt-dlp) desde la app.

## Instalar

1. Descarga el APK desde [Releases](../../releases/latest).
2. Ábrelo y, si Android lo pide, activa *Instalar apps de orígenes desconocidos*.

## Compilar desde el código

1. Abre la carpeta en Android Studio (Koala o superior).
2. Espera a que sincronice Gradle.
3. Conecta un móvil o emulador y pulsa **Run**.
